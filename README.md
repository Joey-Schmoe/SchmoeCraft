# SCHMOECRAFT MODPACK
**Minecraft 1.21.1 | NeoForge 21.1.265** | **PACKWIZ**  
*A lightweight modpack focused on a three-stage tech progression, enhanced world generation, and quality-of-life.*


## Tech Stages
### Early Game [Create + Storage Drawers]:
>The player is setting up a starter base and covering new-world essentials, setting up basic Create machines for resource gathering and processing, and dabbling in limited Aeronautics vessels. Limited mostly to Water Wheel and Windmill power. Storage is primarily handled with Storage Drawers, and some basic Create storage networking. Pre-potion-brewing status buffs via Farmer's Delight, with full Create integration.

### Mid Game (Create + LaserIO):
>The player has settled into a dedicated base. Create automation is in full swing - proper linked storage vaults, renewable resource generation, dedicated production lines for common craftables and materials, automated Steam Engines for power, long-distance travel and logistics via Trains and Aeronautics vessels. Player is transitioning to electrical transmission of power via Create Crafts & Additions. Player begins to convert logistics networks over to LaserIO, both for instant bulk item transfer and for lag prevention.

### Late Game (Mekanism + Applied Energistics 2):
>This is the mega base stage. Modify or replace Create machines with Mekanism blocks, allowing for significant increases in resource generation and processing, while reducing server lag. Storage moves from Create storage networks over to Applied Energistics networks, allowing for massive, instant, and lag-free storage. Power generation is provided by high-output Mekanism Generators.

## World Gen
### Overworld
>95+ new biomes and massive new terrain features on a foundation of discrete continents seperated by large oceans, built with a tweaked Terralith + Tectonic combination motivating the player to develop transportation methods like Trains and Aeronautics.

### Nether
>BetterNether: New Dawn completely revamps the dimension, restructuring generation to add vertical and volume biome layering, with all-new biomes and structures to explore.

### The End
>Nullscape completely overhauls vanilla End biomes, adds new biomes, and cranks The End's height up to 1.18's enhanced 384 block ceiling.

## Quality-of-Life
### UI
> EMI provides item and recipe display, with full Create supoort for recipe trees

> BetterF3, Enchantment Descriptions, Jade and Pickup Notifier give the player easy access to real-time information

### Functionality  
> Carry On and Trade Cycling make Villager management and mob farms easy to work with  

> JourneyMap, Traveler's Tool Belt, Traveler's Backpack and Waystones reduce friction with vanilla game systems, and enhance playability of the large-scale map.
